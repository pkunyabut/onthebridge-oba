# Blockdit Article Format (EXAMPLE)
Blockdit is a Thai long-form social publishing platform. In this project "Blockdit" is simply the name of the first channel: a long article with a cover image, headings, in-text images with credits, and a Sources list at the end. Rename or replace it for your own platform.

## Format adopted
The template used to instruct the AI to write and lay out for real: [Template/blockdit_article.md](Template/blockdit_article.md)
- A cover image before the content, with a credit under it
- Content divided into sections with headings and blank lines between paragraphs, reading continuously
- Illustrations inserted at the pace of the story, with credits; a closing image is allowed
- A combined Sources list as links at the end. The mapping of claims to evidence is kept in the review sheet. Important claims carry a marker that leads to the list at the end.
- The sample used the headings Hook / Why It Matters / Step-by-Step / Actionable Takeaway, which fit an Explainer. It is an example layout; not every Template must use the same headings.
- Keep sentences whole. Do not detach a number from its unit or split a sentence only to break a block.

## Word count
1,200–1,800 words of English (1,500–2,200 Thai words) for the Blockdit body of every Template, unless the user orders otherwise for a specific piece.
Counting method for new jobs: count the narrative text and sub-headings. Do not count the title / standfirst kept separately, image alt text, image credits, Sources and internal notes.
The count uses `Intl.Segmenter` for the job's language, counting only `isWordLike` segments. Record the Node/ICU version and the counted scope. An author-reported word count is never an automatic check result.
If the piece is too short or too long, adjust the content without adding facts or repetition. If it cannot be adjusted, state the limitation before sending; do not claim it passed.

## Images and sources
Use only real images you have rights to, or images that have already been generated. Label AI-generated images truthfully. Never copy a credit from the example onto another image.
The number of images follows the content. The example had 4; that is not a required number.
If there are no images yet, send the status "draft awaiting images" with proposed insertion points. Do not invent image links and claim it is ready with images.
A link such as images/... is valid only when that file really exists.
An example file is evidence of a format requirement only. It is not evidence that its news, numbers or allegations are true, and it is not an order to approve or publish.

## Status
Applies to new jobs and to jobs that ask for a new format. Old jobs are not edited or approved automatically.
The Human Gate is kept before publishing.
