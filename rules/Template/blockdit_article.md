# Blockdit Article Delivery Template for the AI (EXAMPLE)

Use together with AUTOMATION_RULES.md, BLOCKDIT_FORMAT.md and the chosen writing-approach template.
This is a channel format. It is not a sixth template type and it does not change the template IDs the system uses.

## Writing instructions
Take the topic from the user and keep its meaning. Research and check evidence before writing. Choose Reflective / Opinion / Feature / Explainer to match the intent.
Write 1,200–1,800 English words (1,500–2,200 Thai words), counted as in BLOCKDIT_FORMAT.md, for general readers aged 25–65+.
Use paragraphs that carry a continuous thought, with a blank line between paragraphs. Never split a sentence. Do not write the whole article as a summary list.
Order: cover image → opening → why it matters → main content → takeaway or something the reader can use → closing image where suitable → Sources.
Headings can be adapted to suit the content. "Hook / Why It Matters / Step-by-Step / Actionable Takeaway" are skeleton names from the sample and need not appear in every job.
For a piece that is not a how-to, the main section is explanation, reasoning, a true story, or reflection according to the Template. Never invent practical steps.
Every important claim links to the Sources list at the end by number or source name. Keep Claim IDs and limitations in the separate review sheet; do not put system details in the article.

## Before sending to the owner
- Replace every blank slot with real content. Never send bracketed instructions as an article ready to publish.
- If an image does not exist yet, remove the image slot from the reading copy and keep the plan in image_plan.md, and report it as a draft awaiting images. Never create a link to a file that does not exist.
- AI images must be labelled as AI. A mock-up is not an image proving an event.
- Measure the word count and record the scope counted. Do not include Sources, image credits and a title kept apart from the body.
- Send the article with its review sheet to the user: approve / send back for edits / cancel.
- This format does not approve the facts in the sample document and gives no right to publish by itself.
